Learning paths · Class 1 to PhD

One book, five routes. Pick the path that matches you. Every topic still lives in the syllabus even if you skip a route.

If you start from absolute zero

  1. School chapter → What / History / Types.
  2. Math + Python + Data, then data skills (Ch 30–41, 45: Python depth, Excel, Pandas, SQL, viz, stats, Power BI, capstone, BI compared, engineering, APIs, Git, time series).
  3. Search + Logic (classical AI, still in GATE/UG exams).
  4. ML → nets → NLP → Transformers → GenAI.
  5. Fine-tuning → Agents → Agentic AI → applied production (Ch 42–44 + Ch 46) → frontier (Ch 47–62) → RL.
  6. Theory / XAI / alignment if you want research depth.
  7. Ethics & MLOps. System design + GATE bank + mock interview. Exam.
