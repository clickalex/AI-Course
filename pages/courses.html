4. Is it right for you?

  • Choose it if you have never programmed, want a fast structured start, prefer watching someone write code while you do the same, or want a 4-hour refresher after a break.
  • Skip it if you are already comfortable writing functions, loops and file I/O — go straight to Ch 30, or pick a course on pandas, APIs or ML instead.
  • Be realistic: as the instructor says honestly, no 4-hour course makes you a senior developer. It gives you the foundation this book builds on.

Practice questions

P1. Write a program that asks the user for three numbers and prints the largest one — using only Level 1–3 skills (input, int, if/elif/else).

a = int(input("first: "))
b = int(input("second: "))
c = int(input("third: "))

if a >= b and a >= c:
    print("largest:", a)
elif b >= a and b >= c:
    print("largest:", b)
else:
    print("largest:", c)

Stretch: redo it with a list and a for loop so it works for any count of numbers.

Self-mark:

P2. Write a script average.py that reads scores.txt (one number per line) and prints the average, rounded to 2 decimals. Run it from the terminal.

def read_scores(path):
    with open(path) as f:
        return [float(line) for line in f if line.strip()]

def main():
    scores = read_scores("scores.txt")
    if not scores:
        print("no scores")
        return
    print(f"average = {sum(scores)/len(scores):.2f}")

if __name__ == "__main__":
    main()

Run: python average.py. This combines Level 2 (functions), Level 3 (comprehension-style loops), Level 4 (files, module, terminal) — and mirrors Ch 30 §4–6.
