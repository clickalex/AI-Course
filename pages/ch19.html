Chapter 19 · UG / PhD

Bayesian ML & causal AI

Probability is not enough: causality asks what happens if we intervene.

Figure 19.1 — Arrows encode assumptions; do() cuts the confounding ones.

Graphical models

A Bayesian network is a DAG of conditional probabilities. d-separation tells you which independencies the graph encodes. HMMs are the chain case for sequences; Kalman filters are the linear-Gaussian analogue.

Variational inference and MCMC approximate posteriors when exact inference is intractable (PhD core).

Causal ladder (Pearl)

  1. Association — P(y|x) seeing.
  2. Intervention — P(y|do(x)) doing.
  3. Counterfactuals — “would y have happened if x had been different?”

Confounders create fake correlations. Randomised trials identify causal effects; observational data needs assumptions (back-door, front-door, IV).

ML trap

A model that predicts hospital death from “is on ventilator” should not be used to deny ventilators. That is association, not the effect of the treatment.

Worked example — Bayes on a rare-disease test

Disease prevalence P(D) = 0.01, sensitivity P(+|D) = 0.95, false-positive rate P(+|¬D) = 0.05. After a positive test:

P(D|+) = (0.95·0.01) / (0.95·0.01 + 0.05·0.99) ≈ 0.16. Only ~16% of positive screens are truly sick, because the disease is rare and false positives come from a huge healthy population.

The same lesson governs ML: a “99% accurate” fraud classifier on traffic that is 0.1% fraud may flag mostly innocent customers. Always check precision against the base rate and calibrate probabilities (Platt scaling, isotonic regression) before quoting confidence.

Short notes

Bayes nets = structured probability. Causality ≠ correlation. do-calculus is the algebra of intervention. Use causal thinking whenever a decision changes the world the model was trained on.

Point notes

  • DAG + CPTs = Bayes net.
  • HMM: discrete latent chain.
  • do(x) ≠ condition on x.
  • RCT is the gold intervention.

P1. A startup trains “study hours → marks” and recommends cutting sports. What causal check is missing?

Ability, health, and school quality confound both hours and marks. Intervening on hours (forcing more study by cutting sports) may hurt marks if sports → health → marks. Need a DAG, possible instruments, or an experiment — not just a regression coefficient.

P2. In one paragraph, explain d-separation and why it is useful for inference in a Bayes net.

A path between variables is blocked (given evidence) if it passes through an observed non-collider (chain or common-cause node) or an unobserved collider (common-effect node). If every path between two nodes is blocked they are d-separated, i.e. conditionally independent given the evidence. The property lets the inference engine factor the joint distribution, prune irrelevant variables and query large graphs efficiently — and tells you which variables you actually need to measure.

P3. “Does offering a 10% discount cause repeat purchases?” Design a causal study using (a) an experiment and (b) only historical data.

(a) Randomise customers into treatment/control (RCT) and compare repeat-purchase rates with a confidence interval — randomisation balances unobserved confounders. (b) Draw a DAG (seasonality, new-customer flag, category), block back-door paths by matching or inverse-propensity weighting on pre-treatment variables, use an instrument if available; never condition on post-treatment variables like coupon redemption. Report the estimand honestly: average treatment effect on the eligible population.
