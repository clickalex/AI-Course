Map

  • AI ⊃ ML ⊃ DL. Symbolic rules are AI without learning.
  • ANI exists; AGI/ASI are not products.
  • History: Turing 1950 → Dartmouth 1956 → winters → AlexNet 2012 → Transformer 2017 → LLM era.
  • School: input → process → output; fluent ≠ true; keep secrets off public bots.

Classical AI

  • PEAS; BFS / UCS / A* with admissible h; minimax + α-β.
  • Logic + STRIPS planning + CSPs. Expert-system bottleneck = knowledge acquisition.
  • do(x) ≠ P(y|x). Confounders fake causation.

Math & data

  • Dot product; y = Wx + b; Bayes; w ← w − η∇L.
  • Train / val / test. Fit preprocessors on train only.
  • Leakage and random splits on time/people = fake scores.

Pandas, SQL, viz & stats (Ch 32–35)

Classical ML

  • Loss vs metric. Overfit = train ≪ val error.
  • Precision / recall / F1 / AUC; accuracy lies on imbalance.
  • Logistic = linear classifier. Trees + boosting for tables. k-means / PCA unsupervised.

Deep nets

  • Linear + activation stacked. ReLU hidden; softmax out.
  • Backprop + Adam/SGD. No activation ⇒ still linear.
  • CNN: shared local filters. ResNet skips. Transfer learning on small data.

Language & gen
