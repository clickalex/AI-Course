Curriculum

Complete AI syllabus

School to doctoral research. Expand a level. If a line is here, it is in-scope for “all of AI.”

Class 1–8 · intuition
  • Computers follow instructions; AI also uses data and goals
  • Maps, photo search, voice, spam, game NPCs
  • Input → process → output; sensors and actuators
  • Pattern vs understanding; don’t share secrets with bots
Class 9–12
  • Algorithms; AI vs ML vs DL; ANI/AGI; history
  • Python, tables, charts; train/test; accuracy can lie
  • Chatbots and image generators — hallucinations
Data skills · Python → AI DBs (Ch 30–41, 45, 71–72)
  • Python in depth: types, functions, OOP, files, errors, venvs, debugging
  • Excel/Sheets: $ refs, XLOOKUP, SUMIFS, cleaning, PivotTables, honest charts, Power Query
  • Pandas/NumPy: loc/iloc, groupby/pivot/merge, resample, EDA checklist, vectorisation
  • SQL: SELECT/WHERE/GROUP BY/HAVING, JOINs, CTEs, window functions, NULLs, point-in-time features
  • Visualization: chart chooser, matplotlib/seaborn/plotly, dashboards, storytelling
  • Statistics: median vs mean, CIs, p-values, A/B tests, correlation, Simpson’s paradox, regression
  • Power BI: star schema, DAX measures/CALCULATE, slicers, publish/refresh/RLS
  • Capstone: frame → SQL → clean → EDA → test → memo/dashboard → ML handoff
  • BI compared: Power BI vs Tableau vs Looker vs Excel — pick by team, budget, governance
  • Data engineering: batch vs streaming, warehouses/lakehouses, Spark, Airflow, dbt, quality gates
  • APIs & scraping: REST, pagination, 429 backoff, robots.txt, raw JSONL archives, secrets hygiene
  • Git & collaboration: branching, small PRs, .gitignore, DVC/S3 for data, no secrets in git
  • Time series (Ch 45): decomposition, ARIMA/ETS/Prophet, lag features, rolling backtests, intervals
  • Advanced SQL (Ch 71): windows, RANK/LAG, staged CTEs, EXPLAIN, indexing, dbt
  • AI databases (Ch 72): Postgres+pgvector, Redis caching, vector DBs, tenant isolation
  • Playground: 13 checked SQL/pandas/Excel challenges on built-in datasets (offline)
Undergraduate · Russell & Norvig core
  • Agents as PEAS; environment types
  • BFS, DFS, UCS, IDS; greedy, A*, admissible heuristics
  • Minimax, alpha-beta; CSP; propositional & FOL; expert systems
  • Planning (STRIPS/PDDL); Bayes nets; HMMs; MDPs
  • Linear/logistic, trees, SVM, clustering, PCA, NNs
  • GATE bank: 20 exam-style MCQs — maths, search, ML, DL, SQL
Modern ML & DL
  • SGD/Adam, batch norm, residuals; CNNs, detection, ViT
  • Transformers, BERT, GPT; VAE, GAN, diffusion
  • SSL, CLIP; GNNs; time series; recommenders; IR
  • Speech ASR/TTS; multimodal; AutoML; distillation; GA / swarm / fuzzy
Industry · LLMs, agents, MLOps
  • Prompting, tools, function calling, MCP-style servers
  • RAG, rerankers, citations, evals
  • SFT, LoRA/QLoRA, DPO/RLHF, guardrails
  • AI Agents and Agentic AI: plan–act–observe, memory, multi-agent
  • Tracing, cost, prompt injection, HITL, drift
  • Applied production (Ch 42–44, 46, 67–70, 73–74): prompt patterns, RAG + evals, Docker, cloud GPUs, MLOps lifecycle, transformers lab, DSA I–III, model serving + demos, terminal survival, Kubernetes for ML
  • Transformers lab (Ch 46): tokenizers, LoRA/QLoRA, golden evals, vLLM serving, guardrails
  • Interview Q&A bank: 24 Python/SQL/ML/LLM/MLOps/HR questions with model answers
  • System design: video recsys, fraud detection, RAG at scale — framework + trade-offs
  • Mock interview mode: timed random draws with self-scoring and best-score tracking
  • Frontier (Ch 47–66): AGI, RAG+, reasoning, edge, VLMs, voice, video, federated, quantum, robotics, science, recsys, injection defence, economics, MM-evals, red-teaming, code agents, synth data, Indic, training data
PhD / research
  • PAC, VC dimension, Rademacher; nonconvex opt; scaling laws
  • Causal DAGs, do-calculus; VI, MCMC
  • Deep RL, offline RL, MARL, world models
  • Mechanistic interpretability; SHAP limits; alignment
  • Adversarial ML; DP; neuro-symbolic; MoE; paper craft

Use as a GATE / interview / qualifier checklist. Chapters teach ideas; a PhD still needs papers, proofs, and experiments.
