Data analysis with Pandas & NumPy

Excel shows you the data. Pandas lets you reshape a million rows in seconds — reproducibly. This is the core skill between spreadsheets and machine learning.

1. NumPy in 10 lines: vectors beat loops

import numpy as np
a = np.array([1., 2., 3.])
print(a * 2, a @ a)          # [2.4.6.] 14.0  (elementwise, dot)
M = np.arange(12).reshape(3, 4)   # shape (3,4)
print(M.mean(axis=0))        # column means — no Python loop
# broadcasting: (3,4) + (4,) → each row + vector

Broadcasting aligns trailing shapes. If shapes mismatch, NumPy errors — that error is usually telling you your features/labels are misaligned.

2. DataFrame mental model

A Series is a labelled column; a DataFrame is a dict of Series sharing an index. Think Excel table + index + dtypes.

import pandas as pd
df = pd.read_csv("data/raw/sales.csv")
print(df.shape)
print(df.dtypes)        # object = strings, int64/float64, datetime64, category
df.head(3); df.info(); df.describe(include="all")

3. Select without tears: loc / iloc / masks

# rows, cols
west = df.loc[df["region"] == "West", ["date","amount"]]
top5 = df.nlargest(5, "amount")
# boolean masks combine with & | ~  (parentheses required!)
mask = (df["year"] == 2025) & df["amount"].gt(1000) & df["status"].ne("refunded")
print(df.loc[mask].shape)
# query is readable for long filters
print(df.query("year==2025 and amount>1000 and status!='refunded'").shape)

SettingWithCopy

Never chain assignment like df[df.x>0]["y"]=1 — it may silently fail. Always df.loc[mask, "y"] = 1.

4. Cleaning: the 80% workflow

# dates, strings, numbers
df["date"] = pd.to_datetime(df["date"], errors="coerce")   # bad → NaT
df["city"] = df["city"].str.strip().str.title()
df["amount"] = (df["amount"].astype(str).str.replace(r"[₹,]", "", regex=True)
                  .pipe(pd.to_numeric, errors="coerce"))

# missing + dupes
print(df.isna().sum().sort_values(ascending=False).head())
df["amount_missing"] = df["amount"].isna().astype(int)  # the flag is a feature!
df["amount"] = df["amount"].fillna(df["amount"].median())
df = df.drop_duplicates(subset=["order_id"])

# categories save memory + order plots
df["region"] = df["region"].astype("category")

5. Split–Apply–Combine: groupby / pivot / merge

Diagram 32.1 — Every groupby/pivot is split–apply–combine. Reset the index before the next join.
# groupby: one row per group
monthly = (df.assign(ym=df["date"].dt.to_period("M").astype(str))
             .groupby(["region","ym"], as_index=False)["amount"]
             .agg(total="sum", orders="count", avg="mean"))

# pivot: groups as a grid (like PivotTable)
piv = df.pivot_table(index="region", columns="year", values="amount",
                     aggfunc="sum", fill_value=0, margins=True)

# merge: SQL join in pandas (validate your keys!)
orders = pd.read_csv("orders.csv"); cust = pd.read_csv("customers.csv")
m = orders.merge(cust, on="customer_id", how="left", validate="many_to_one")
print(m["customer_id"].isna().sum(), "orders with no customer match")

6. Time series: resample + rolling

ts = df.set_index("date").sort_index()
monthly_sales = ts["amount"].resample("ME").sum()
trend = monthly_sales.rolling(3, min_periods=1).mean()  # 3-month moving avg
print(pd.concat([monthly_sales, trend], axis=1).tail())

7. EDA checklist (run every time)

  1. Shape + types: rows, cols, dtypes, nunique per column. Is order_id unique?
  2. Missing: % missing, why missing (never vs not-yet)? Add flags.
  3. Distributions: describe, histograms of amount/age, value_counts of categories. Log-scale long tails.
  4. Time: rows per day — gaps = broken pipeline, spikes = sale or bug.
  5. Relations: correlation of numerics, groupby means, scatter of price vs qty.
  6. Leakage hunt: any column known only after the target? Drop it.
  7. Write 5 bullets a manager can use. If you can’t, you haven’t finished EDA.

8. Fast pandas (when it feels slow)

  • Vectorise: df["total"]=df["qty"]*df["price"], not apply per row. apply is a loop in a costume.
  • Types: category for low-cardinality strings, int32/float32, parse_dates once.
  • Filter early: drop rows/cols before heavy groupbys. Use usecols in read_csv.
  • Chunks: pd.read_csv(..., chunksize=100_000) for files bigger than RAM.

End-to-end snippet — monthly West sales

(df.assign(ym=df["date"].dt.to_period("M").astype(str))
   .query("region=='West' and status!='refunded'")
   .groupby("ym", as_index=False)["amount"].sum()
   .sort_values("ym").tail(6))

Short notes

NumPy = vectorised arrays + broadcasting. Pandas = DataFrames with loc/iloc, dtypes, groupby/pivot/merge, resample. Clean in order (types → strings/dates → missing → dupes), validate joins, filter early, vectorise instead of apply. EDA ends with written findings, not just plots.

Point notes

  • loc by label, iloc by position.
  • loc[mask, col] = … for assignment.
  • Missing flag is a feature.
  • groupby → agg → reset_index.
  • Merge with validate; check unmatched keys.
