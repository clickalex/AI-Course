P2. [Course 1] Write a script average.py that reads scores.txt (one number per line) and prints the average, rounded to 2 decimals. Run it from the terminal.

def read_scores(path):
    with open(path) as f:
        return [float(line) for line in f if line.strip()]

def main():
    scores = read_scores("scores.txt")
    if not scores:
        print("no scores")
        return
    print(f"average = {sum(scores)/len(scores):.2f}")

if __name__ == "__main__":
    main()

Run: python average.py. This combines Level 2 (functions), Level 3 (comprehension-style loops), Level 4 (files, module, terminal) — and mirrors Ch 30 §4–6.

P3. [Course 2] A team wants to predict monthly rent from a labeled table of 10,000 listings (area, bedrooms, neighbourhood, rent). Name the paradigm, say whether the target is continuous or categorical, and describe what over-fitting would look like here plus one way to catch it.

Paradigm: supervised learning, specifically regression (rent is a continuous number, not a category). Over-fitting: the model exploits quirks of these 10,000 rows (e.g., a specific landlord’s naming style) and predicts well on them but poorly on new listings. Catch it with a hold-out set (or cross-validation): train on one split, evaluate on data the model never saw — a big train/test gap is the warning sign (Ch 7).

Self-mark:

P4. [Course 2] Draft a prompt that asks an LLM to summarize a 10-page report for a busy CEO. Then list three limitations from the course that could affect the output, and one mitigation for each.

Example prompt: “Summarize the attached 10-page report in 5 bullet points for a CEO: lead with decisions needed, keep numbers exact, no new facts.”

Limitations: (1) Prompt sensitivity — vague prompts give vague summaries; mitigate with explicit instructions (audience, length, focus) as above. (2) Hallucination — the model may add plausible-but-wrong “facts”; mitigate with “no new facts” instructions and spot-checking bullets against the source. (3) Knowledge cutoff / context limits — anything not in the prompt or report is unknown to the model; mitigate by pasting the relevant report text (or using retrieval, Ch 42/48).
